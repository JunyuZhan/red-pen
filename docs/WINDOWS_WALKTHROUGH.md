# Windows 真人装机走查清单

> 用途：第一次给老师装机时照着走一遍，每步都有「预期结果」和「失败怎么办」。全程约 15 分钟。走查完成后请在末尾记录结果，反馈给开发者。

## 准备
- Windows 10/11 电脑一台（64 位），可上网（调云端 AI 用）
- 手机一部，与电脑连**同一个 Wi-Fi**
- 一份学生作业照片（清晰、光线均匀）
- AI 模型的 API Key（如 DeepSeek / 通义千问 / 智谱）

## 第 1 步：下载与首次运行
1. 浏览器打开 https://redpen.zhanjunyu.com/download.html ，下载最新版 exe。
2. 双击运行。若弹出 **SmartScreen 蓝色警告**：点「更多信息」→「仍要运行」。
   - 若杀毒软件报毒：在杀毒软件里选「信任 / 加入白名单」（未买代码签名证书，属常见误报）。
3. 黑色控制台窗口出现，几秒后浏览器自动打开工作台。

**预期结果**：浏览器显示红笔工作台登录页。
**失败**：浏览器没自动打开 → 手动访问 `http://localhost:8080`；还不行 → 看控制台窗口报错，截图反馈。

## 第 2 步：首次登录与改 PIN
1. 输入默认 PIN **123456** 登录。
2. 立即进「设置」→ 修改 PIN。**确认新 PIN 能登录**（退出重登一次）。

**预期结果**：旧 PIN 失效，新 PIN 可登录。

## 第 3 步：首次引导
按提示完成学段/学科/班级设置，并建 1-2 个测试学生（名字随便填，如「测试一」）。

**预期结果**：工作台班级列表出现测试班级和学生。

## 第 4 步：配置模型并「测试连接」
1. 设置 → 模型配置：选服务商、填 API Key。
2. 点「**测试连接**」。
   - 绿色 = Key 有效且该模型支持看图。
   - 若提示「该模型不支持图片输入」→ 换设置页推荐清单里的视觉模型。
3. 顺手记一下成本预估显示是否正常（老师付费，月底看用量）。

**预期结果**：测试连接绿色通过。
**失败**：401 → Key 抄错或未生效；「余额不足」→ 去厂商控制台充值；限流/超时 → 稍后重试。

## 第 5 步：手机扫码连接
1. 电脑端设置 →「手机连接引导」，页面上有局域网地址（形如 `http://192.168.x.x:8080`）和二维码。
2. 手机浏览器扫码打开手机端页面。
3. 如手机打不开：
   - Windows 首次运行弹出「**Windows 安全中心警报**」（防火墙）时必须勾选「**专用网络**」并点「允许访问」；若当时点错：控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙 → 找到 red_pen 勾上「专用」。
   - 确认手机与电脑在同一 Wi-Fi；部分路由器开了「AP 隔离/访客网络」会屏蔽内网互访，需在路由器关闭。

**预期结果**：手机端能登录并拍照。

## 第 6 步：外网检查
手机端或电脑设置页有「测试外网」，点击。

**预期结果**：「外网连接正常，可以调用云端 AI 批改」。

## 第 7 步：完整批改链路
1. 手机端选测试学生 → 拍作业照（故意拍一张模糊的，验证会**标红提示重拍**，可强行上传）→ 上传。
2. 电脑工作台发起批改，观察：
   - 批改过程中控制台/页面状态流转（排队 → 批改中 → 完成）；
   - 完成后逐题判定、置信度、红笔标注图是否显示；
   - 标注位置是否压在对应题目上（不准的记下题号）。
3. 试一次「重批」和一次「归属改错？」按钮。
4. 看板页：作业概览、知识点、高频错题三层数据是否出现。

**预期结果**：全链路无卡死，结果可复核。
**失败**：卡「批改中」超过 2 分钟 → 设置页「运行日志」卡 → 打开 `data/logs/redpen.log`，把最近几十行截图反馈。

## 第 8 步：数据安全
1. 设置 → 备份：创建备份，确认生成 zip 文件。
2. （可选，谨慎）恢复演练前先手动再备一份，再用刚生成的备份恢复，确认数据一致。

## 第 9 步：关机/重启恢复
关闭控制台窗口 → 重新双击 exe。之前上传的作业、批改记录应仍在（数据存 exe 同级 `data/` 目录，别删这个文件夹）。
