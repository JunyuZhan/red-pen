安装说明（图文版请看使用教程）

  1. 下载 RedPen.exe，放入新建文件夹（如 D:\红笔）——数据会存在同级的 data 文件夹
  2. 双击运行；首次运行遇"Windows 已保护你的电脑"：点 更多信息 → 仍要运行
  3. 杀毒软件误报请添加信任（官方渠道下载的文件没有病毒）
  4. 浏览器自动打开工作台，用默认 PIN 123456 登录后立即修改
  5. 到设置页配置模型 API Key（详见教程第 4 步）
