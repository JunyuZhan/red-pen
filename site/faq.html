FAQ

常见问题

双击 exe 提示"Windows 已保护你的电脑"，怎么办？

这是 Windows 对没有代码签名证书软件的标准提示，不代表有病毒。点 更多信息 → 仍要运行 即可，之后不再出现。我们未购买签名证书（费用每年数千元），把这笔钱省下来让软件保持免费。请务必从本官网或 GitHub Releases 下载以确认文件来源。

杀毒软件（360/火绒/Defender）报毒了？

红笔由 Python 打包而成，这类打包格式是杀毒软件误报的重灾区。请选择"信任/加入白名单"。如果你不放心，可以在 GitHub 上查看全部源代码——软件是开源的，每一行都公开可查。

API Key 是什么？要花钱吗？

API Key 是大模型服务的专属密钥，AI 批改能力来自它。需要到模型厂商（DeepSeek/通义/智谱）注册并充值，按用量计费：以 DeepSeek 为例，批改一份作业约几毛钱，10 元大约够批 30-50 份，余额永久有效。详细申请步骤见使用教程第 4 步（有截图）。

软件本身收费吗？

永久免费。开源协议（PolyForm Noncommercial）允许个人与学校/教师自由使用；唯一的限制是未经作者授权不得将软件本身用于商业用途。你的花费只有模型 API 的使用费，直接付给模型厂商，与作者无关。

学生的作业照片和成绩会被上传到哪里？

作业照片只发往你自己配置的模型服务商（用于识别批改，这是必须的）；所有成绩、学生信息、API Key 都保存在你电脑本地的数据库，不会传给开发者或任何第三方。建议在拍照前遮盖试卷上的学生真实姓名等敏感信息，并关闭模型服务商的"数据用于训练"授权（设置页有详细说明）。

换电脑了，数据怎么办？

设置页 → 数据备份 导出 zip（含全部数据库+作业照片）→ 新电脑装好红笔 → 数据恢复 导入 zip，完整迁移。建议平时定期备份到 U 盘或网盘。

手机扫码后打不开页面？

三个最常见原因：① 手机和电脑不在同一个 WiFi；② Windows 防火墙拦截——首次运行弹出的"允许访问网络"要点允许（错过就去 控制面板 → 防火墙 → 允许应用通过防火墙 勾选）；③ 电脑用了 VPN/代理——先关掉再试。

AI 批改的准确吗？判错了怎么办？

准确率是本软件的第一优先级：图像质量门禁挡掉模糊照片、参考答案注入、规则交叉校验、低置信度自动交叉复核。但 AI 无法保证 100% 正确——所以所有没把握的题目会诚实标记并进入复核列表，你点一下即可修正。建议重要考试的成绩以你复核后的结果为准。

批改速度慢 / 一直转圈？

单份约 20-60 秒，取决于模型服务商的响应速度。如长时间无结果：检查设置页 API Key 是否有效（点"测试连接"）；检查电脑是否断网；失败的作业会在工作台出现"重试"按钮，不会丢。
