批改引擎设置

选择 AI 服务商并填写 API Key，Key 保存在本机数据库，不会上传到任何第三方。
自定义服务商时必填，一般以 /v1 结尾

成本单价配置

配置每 1K tokens 的单价（元），用于估算批改花费，仅保存在本机。

成本估算器

按 PRD 4.3 公式估算：单份成本 ≈ 题目数 × (单题输入token × 输入单价 + 单题输出token × 输出单价)。厂商价格随时变，此处只给算法不给死价。
—

备用引擎（自动切换）

主服务商批改失败或限流时，自动降级到备用引擎重试一次；不填服务商即关闭备用切换。

查不到 IP？分系统查看方法
Windows 10：设置 → 网络和 Internet → WLAN/以太网 → 点当前网络 → 属性 → 找 IPv4 地址
Windows 11：设置 → 网络和 Internet → WLAN → 点当前网络，直接看 IPv4 地址（备用：cmd 输入 ipconfig）
Mac：系统设置 → 网络 → Wi-Fi → 详细信息 → TCP/IP → 看 IP 地址
注意：手机和电脑必须连同一个 WiFi；连不上时检查电脑防火墙是否放行本程序（8080 端口）。
