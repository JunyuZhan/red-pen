安装说明（图文版请看使用教程）

  1. 下载 RedPen.exe，放入新建文件夹（如 D:\红笔）——数据会存在同级的 data 文件夹
  2. 双击运行；首次运行遇"Windows 已保护你的电脑"：点 更多信息 → 仍要运行
  3. 杀毒软件误报请添加信任（官方渠道下载的文件没有病毒）
  4. 浏览器自动打开工作台，用默认 PIN 123456 登录后立即修改
  5. 到设置页配置模型 API Key（详见教程第 4 步）

v0.5.15 OCR 增强

设置页新增「OCR 增强」开关（默认关）：开启后切题时识别页面文字改用 DeepSeek 服务端 OCR（约 1.5 元/1000 页），手写/印刷混排识别更稳；仅 DeepSeek API 生效，其它供应商自动回退本地识别。

v0.5.14 跨页续题

作业拍多页、题目被页边界切开时，自动把上一页尾题与下一页首题拼图重批补全答案与判定；另含拍照分组（同一位拍下一页/下一位）交互。

v0.5.13 切题说明段落误圈剔除

「注意事项/答题要求」等说明段落不再被当成题目切出；另含 v0.5.12 修复：切题冗余「未作答」清理。

v0.5.12 切题冗余未作答清理

  • 解答题/多步计算题 AI 逐步骤定位：只列做错的步骤及错因，批改详情页直接展示「第几步错在哪」，讲评不用逐行找；口算、选择题自动跳过（省 token）

v0.5.10 一键体验演示

  • 工作台新增「生成演示数据」按钮：没填 AI Key 也能先看完整批改产物（作业列表、题目判定、学情统计、各导出）。所有数据带【演示】标记（内置示例、非 AI 批改），可一键清除，不影响真实班级

v0.5.9 设置页「测试外网」
