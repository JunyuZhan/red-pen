安装说明（图文版请看使用教程）

  1. 下载 RedPen.exe，放入新建文件夹（如 D:\红笔）——数据会存在同级的 data 文件夹
  2. 双击运行；首次运行遇"Windows 已保护你的电脑"：点 更多信息 → 仍要运行
  3. 杀毒软件误报请添加信任（官方渠道下载的文件没有病毒）
  4. 浏览器自动打开工作台，用默认 PIN 123456 登录后立即修改
  5. 到设置页配置模型 API Key（详见教程第 4 步）

v0.5.20 管理路由孤儿防护（健壮性加固第三轮）

  • 删除班级防护：班级下还有作业时禁止删除，避免历史作业/成绩悬空
  • 删除学生防护：学生已有作业记录时禁止删除，避免错题本与学情分析数据失真
  • 改学生班级时校验目标班级存在，不再把学生改成无主状态

v0.4.14 标注不遮挡原字（准确率专项）

  • 错题标注改为：小错号贴在题目右上角，短错因（如"计算错误"）以白底红字标注在题目外侧（右侧→左侧→下方自动选位），不再整框圈住学生手写内容
  • 答对的题只画贴角小对勾，同样不画大圈遮挡

v0.4.13 红笔压手写（准确率专项）

  • 批改标注收紧到手写墨迹：红笔/绿笔直接圈住学生写的字，不再压在题干印刷文字或空白处
  • 题目区域内找不到笔迹时自动回退原定位，批改永不中断

v0.4.12 切题定位大升级（准确率专项）

  • 题号锚点定位：OCR 识别「1. / 12、/ (3)」等题号，按锚点重建题目区域，页眉/姓名栏/标题不再被误标（本地离线识别，数据不出机）
  • 定位不可信时按老师答案表的题数切分，红笔标记铺满整份作业
  • 隐私遮盖默认关闭（姓名不敏感，遮顶会伤识别）
  • GitHub Release 说明改为自动取自更新日志，每版写清更新内容

v0.4.10 ~ v0.4.11 隐私与置信度

  • v0.4.11 置信度融合第四因子：知识点历史准确率，弱项题自动进复核、强项题少打扰
