# 红笔 · 教师单机自用版

基于PRD V0.4实现的教师作业自动批改系统。

## 项目结构
```
red-pen/
├── backend/                 # 后端服务
├── frontend/               # 前端界面
├── models/                # AI模型适配器
├── database/              # 数据库相关
├── config/               # 配置文件
└── docs/                 # 文档
```

## 功能特性
- ✅ 手机拍照上传作业
- ✅ 云端大模型自动批改
- ✅ 原图批改结果回显
- ✅ 教师看板分析
- ✅ 多学段学科班级支持
- ✅ 成本估算与控制
- ✅ 数据备份恢复

## 快速开始
1. 安装依赖
2. 配置API Key
3. 启动服务
4. 访问 http://localhost:8080
5. 手机扫码使用
